# 📸 Image Assets Directory

To customize the website with your own photos, place your images in this folder (`assets/`) with the following filenames:

1. **`teddy_bear.png`** - Image for Slide 1 (Teddy bear holding a bouquet or any cute welcome graphic).
2. **`couple_photo.jpg`** - Image for Slide 2 (Portrait photo of you and your girlfriend, approx 260px x 320px).
3. **`polaroid_1.jpg`** - Memory Photo 1 for Slide 3 (e.g. Sunset beach / date 1).
4. **`polaroid_2.jpg`** - Memory Photo 2 for Slide 3 (e.g. Coffee shop date).
5. **`polaroid_3.jpg`** - Memory Photo 3 for Slide 3 (e.g. Stargazing / night out).
6. **`polaroid_4.jpg`** - Memory Photo 4 for Slide 3 (e.g. Amusement park / special moment).

*Note: The application has built-in graceful fallback placeholders with cute gradient frames if an image file is missing or still being uploaded!*
